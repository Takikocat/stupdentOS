# stupdentOS

A small operating system project written in Rust for learning low-level systems.

This project follows the second edition of
*Writing an OS in Rust* by Philipp Oppermann, with additional experiments
and notes as I learn.

## Goals

- Understand how a freestanding Rust binary works
- Learn `no_std` development
- Explore CPU exceptions and interrupts
- Understand paging and memory management
- Experiment with kernel-level Rust and `unsafe`

## Status

Early development.
